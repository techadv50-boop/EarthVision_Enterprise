WorkPilot.exe is the one-employee pilot for this Windows 11 Pro PC.

1. Update Windows first if the PC is still on build 22000. Stay on Windows 11 Pro.
2. Copy WorkPilot.exe to the PC. A USB drive or a shared folder is enough.
3. Double-click WorkPilot.exe.
4. If Windows SmartScreen appears, choose More info, then Run anyway.
5. Approve the administrator prompt.
6. The window has buttons on the left. Employee login is where you create the login. The other buttons are Live activity, Activity log, Programs, Storage, and Beep and time. The defaults are login employee1, 80 GB, 1 minute before the report counts idle, and 30 seconds before the beep.
7. Sign in as that employee at this computer. Live activity shows Working in green. After the beep time with no mouse or keyboard, Not working turns red and this computer beeps until the employee uses the mouse or keyboard again. Activity log shows the sites, programs, and time on the computer.
8. On your other computer, open the same WorkPilot.exe, click "Watch employee", and set the watch address to http:// and this PC's Tailscale address, then :8777/status. That window uses the same green and red buttons and beeps while the light is red.
9. Sign out, wait one minute, and open "Work session report" on the administrator desktop.

The report shows programs, window titles, active time, and idle time. It does not record keystrokes, screenshots, or passwords.

Do not open Remote Desktop directly to the internet. Use a private network such as Tailscale, then connect with Remote Desktop.

Block other programs only after one real work day looks right. Use the button "Block other programs" in WorkPilot.
