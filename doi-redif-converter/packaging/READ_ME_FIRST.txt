READ ME FIRST — Standalone v1.4.1
=================================

This program is a NATIVE DESKTOP APP.
Window title includes: Standalone v1.4.1

Why counts differ from OJS editorial Archives
---------------------------------------------
Editorial "Archives" (e.g. 1731) includes declined/unpublished submissions.
This crawler collects PUBLIC published article page URLs only.

v1.4.1 uses the journal sitemap (plus archive links), so older issues
missing from the archive page are included too.

How to run (Windows)
--------------------
1. Unzip into a NEW empty folder
2. Double-click: Run_Standalone.bat
3. Paste archive URL, click "Crawl article URLs"
4. Review URLs, then "Start conversion"

Example:
https://journal.50sea.com/index.php/IJIST/issue/archive
