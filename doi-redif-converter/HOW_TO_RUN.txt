DOI / URL → ReDIF Converter (Standalone)
========================================

This is a desktop program. It opens its own window.
It does NOT require a browser.

Windows
-------
1. Unzip DOI_REDIF_Converter-windows.zip
2. Double-click Run_DOI_REDIF_Converter.bat
   (or DOI_REDIF_Converter.exe)
3. If SmartScreen appears: More info → Run anyway

What you can paste / upload
---------------------------
- DOIs: 10.33411/IJIST/1936
- DOI links: https://doi.org/10.33411/IJIST/1936
- Article page URLs (even without DOI):
  https://journal.50sea.com/index.php/IJIST/article/view/1936

One item per line.

Using the app
-------------
1. Paste DOIs/URLs or click Load Excel/Text
2. Click Start conversion
3. Watch progress (done / left)
4. Bad/404 items are skipped automatically
5. At the end, use:
   - Export ZIP…
   - Save .redif folder…
6. Report files included:
   - _conversion_report.txt
   - _failed.csv

If it fails to open
-------------------
Check DOI_REDIF_Converter.log in the same folder.
